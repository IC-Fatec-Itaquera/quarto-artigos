# Katex
## oque é 
a mais rapida biblioteca de simbolos matematicos
## oque resolve
ela permite que usemos simbolos matematicos mais precissos do que apenas os caracteres 64 bit do teclado comun 

ela permite que inves de fazer isso :

- P(x) = e^beta0+beta1*X1/1+e^beta0+beta1*X1

a gente possa fazer isso: 

$$
    P(x) = \frac{e^{\Beta_0+\Beta_1*X_1}}{1+ e^{\Beta_0+\Beta_1*X_1}}
$$
